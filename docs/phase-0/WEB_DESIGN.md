# Phase 0 Web Design Record

Design Read: wallet and contract proof shell for builders and hackathon reviewers, in a restrained editorial-fintech language, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

## Major decisions

- Color: warm paper and deep forest communicate a working ledger; amber is reserved for testnet and attention states.
- Layout: the page reads as one sequential verification record because Phase 0 has a single proof path, not a dashboard hierarchy.
- Typography: an old-style serif gives the proof headings institutional weight; a legible humanist sans carries instructions; monospace is limited to machine values.
- Spacing: generous introduction spacing separates purpose from execution, while denser proof rows keep related evidence together.
- Containers: one bordered proof surface groups the three dependent checks; repeated floating cards would incorrectly imply independent features.
- Motion: only state and hover transitions are used because financial verification benefits from stability, not choreography.
- Identity motif: numbered ledger rows and thin accounting rules repeat the idea that every claim needs traceable evidence.
- Theme: the fixed light theme resembles a readable audit sheet and keeps contrast predictable during the Phase 0 proof.
